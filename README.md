# Utazási iroda katalógus

## Alapfeladatok (2 pont):
### Készítse el a Világraszóló Utazási Iroda virtuális katalógusát. A rendszernek adatbázisban kell tárolnia a lehetséges célpontokat (ország), valamint a közlekedési eszközt (autó, busz, repülőgép). Az egyes célpontokra különböző időpontokban lehet utazni. Ezeket az időpontokat egy kapcsolt táblában szükséges tárolni, az utazás árával együtt. Egy célponthoz tetszőleges számú időpontot lehet rendelni.
### Az alapfeladat során a program nyitóoldalán ki kell listázni az egyes célpontokat, a hozzá tartozó közlekedési eszközzel, lapozóval együtt. Egy célpontot kiválasztva listázzuk ki az indulások időpontját, valamint a hozzá tartozó árat is. Amennyiben egy adott célponthoz nincsen elérhető utazási időpont, ezt jelezzük a felhasználónak.
### Az alapfeladat során nem szükséges CRUD rendszert megvalósítani. Az adatbázis feltöltésére készítsen Factory osztályokat! A routing fájlokba ne kerüljön üzleti logika, csak a routing szabályokat tartalmazhatja!

#### Az alapfeladatokat teljesítve a hallgatók 2-es osztályzatot kapnak.

## Plusz Feladatok:
 1. Az alapfeladatok mellett az alábbi plusz feladatokat lehet megoldani. Minden pluszfeladat 1 pontot ér, ami egyenként eggyel javítja az osztályzatot.
 2. Készítsen egy CRUD rendszert, amelyen keresztül kezelhetőek a célpontok, valamint a hozzá tartozó időpontok is!.
 3. Regisztráció és bejelentkezést követően legyen lehetőség jelentkezni egy utazásra. A jelentkezés adatait tároljuk el egy adatbázisban, a felhasználót pedig tájékoztassuk!
 4. Keresési funkciók implementálása: lehessen keresni célpontra, vagy utazás időpontjára.
 5. Biztosítson egy API végpontot ugyanezen funkciókra.
 6. Egy utazáshoz lehessen megadni egy képet. A kép jelenjen meg a lista oldalon, illetve a célpont saját oldalán is.
